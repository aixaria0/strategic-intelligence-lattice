# Original prototypes and working drafts

This directory preserves alternative concepts and fragments from the design conversation. **Do not treat them as current production modules or validated research.** Some examples are intentionally flawed or depend on unavailable files. Keep them for historical comparison, test-case generation, and archaeological reproduction.

original_paper_draft.tex is the user-supplied first manuscript, including historically unproven assertions and schematic TikZ drawings. docs/paper.tex is the qualified working note. snippets/ contains *selected historical excerpts and reconstructed examples*, not a byte-for-byte export of the complete chat. archive/PROTOTYPE_CATALOG.md inventories the full range of conceptual variants. A literal transcript requires an actual chat export, scrubbed of secrets before committing to this public repository.
