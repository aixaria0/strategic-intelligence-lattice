Preserve conceptual stages, abandoned examples, unproved assertions, contradictory equations and implementation status without silently rewriting or deleting them. These records are a structured recovery of the conversation, **not** a verbatim chat export. Export the original chat separately if byte-for-byte completeness is required; remove secrets and private data before adding it to this public repository.

Status terms: HISTORICAL, HYPOTHESIS, INVALID AS STATED, SKETCH, IMPLEMENTED LOCALLY, PROPOSED, EXPERIMENTAL. Do not infer operational readiness or mathematical validity from a file existing.
